# Final deliverables

## ICS event assignment prototype

[Open the ICS 203 / ICS 204 prototype](ics-assignment-prototype.html)

This single-file browser prototype demonstrates an automatically populated ICS 203 organization assignment list and related ICS 204 personnel assignment sheets. It implements the October 29, 2026 project scope: the Deputy Fire Chief and division leaders can review an event roster, verify assignments, and evaluate usability by November 19, 2026. The October 29 project-scope document remains unchanged.

### Run it

1. Download `ics-assignment-prototype.html` from this folder (use GitHub's **Raw** view, then save the page as an `.html` file), or clone/download the repository.
2. Open the saved HTML file in a current desktop or mobile browser. No server, account, installation, or internet connection is needed after download.
3. Select **Load sample event** to restore the demonstration data. Edits autosave in that browser on that device.
4. Select **Validate assignments** to check required fields and whether the event period ends after it starts. The checks catch omissions; they cannot determine whether an assignment is operationally correct.
5. Select **Print / save as PDF** to print the ICS 203 roster and ICS 204 sheets.

### Sample walkthrough for the department

The sample is a fictional community resilience fair on November 19, 2026. All people, agencies, contacts, locations, and assignments are invented. It demonstrates a command/general staff roster and three generic event-support assignments: visitor welcome, accessibility and family support, and site services. It is not an operational plan.

During the walkthrough, the Deputy Fire Chief and division leaders can:

- Compare each ICS 203 role and name with the approved fictional test roster.
- Trace each ICS 204 supervisor, assigned personnel, reporting point, time period, task, resources, instructions, and communications reference back to the intended organization.
- Edit one or more fields, add an assignment sheet, and run validation.
- Print or save the populated forms as a PDF and judge whether the information is easy to find and legible.
- Enter accuracy, ease-of-use, and print-readability ratings and record corrections in the evaluator section.

The prototype stores edits and evaluator notes only in the current browser's local storage; it does not transmit data. **Clear saved edits** restores the fictional sample. For the November 19 session, first confirm the sample with the team and replace it with an approved, non-operational test roster. Do not enter real personnel details, sensitive contacts, or live response assignments.
